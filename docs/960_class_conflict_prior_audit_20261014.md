# 跨视图类别分歧候选：近邻方法与创新边界

日期：2026-10-14。先做近邻核查和缓存空间筛选，不主张已有核心创新。

FUSE 的作者仓库说明三层检测融合包含 objectness、框与分类融合，
对应 KDD2021 论文 Robust Object Detection Fusion Against Deception。
因此，“把不同检测输出的类别证据合并”已经有先例。

FUSEye 的 arXiv2610.02799v1（2026-10-02）方法包含重叠全局/切片视图、
IoU 图分组、坐标融合与轻量前馈评分。按类别分图的机制位置已读，
但没有运行或完整复现该预印本，也不能声称超过它。
重叠切片、框特征重评分和加权融合本身不能作为本项目原创贡献。

本轮具体候选是：原图与放大切片出现类别分歧时，裁剪尺度、目标可见程度
和附近上下文完整度，是否能判断哪份标签证据更可靠。
候选任务保持既有原框坐标、置信度、数量和顺序，仅在已有视图支持的类别中选择。
它不同于上一轮只改坐标或修改检测器最后分类投影，但任务不同不等于首创。
分类融合、尺度感知及裁剪可靠性本身都需要更完整的近邻对照。

投入顺序：缓存标注辅助空间 -> 训练集内小头场景留出 -> 头种子重复 ->
有证据才扩大数据并做官方评价。小头要与普通投票及同容量、相同类别证据、
不使用观察条件的学习头比较。若普通方法已经解释收益，不将整体涨点归给新机制。

# 当前小目标研究范围的投入结论

2026-10-15。结论：建议停止当前“基于既有YOLO11s-960权重、既有预测/特征、
小头和局部干预，在已使用的VisDrone DET分割上继续筛修补方案”的搜索。
保留960与普通校准版作为工程资产，不再为这批失败配方追加完整训练。

这是有范围的资源分配建议，不是证明小目标检测没有创新空间。没有找到
同时具备清楚先例差异、可部署收益和足够确认依据的新研究候选。本次
没有把“找到创新”改判为成功，而是采用原目标允许的另一终点：
基于明确覆盖范围的证据提出停止当前研究范围的建议。

## 本轮实际核验了什么

本轮是回顾性审计，不是第70个检测方法实验，也不是在历史结果未知时
预注册的研究。历史结果已知这一点记录在审计协议中。

- 逐条读取candidate1至candidate69，保留每条原始结论和文件哈希。
- 识别16条明确的正向或允许后续试验的记录，逐条列出后续验证或工程保留去向。
- 重算当前6471张train、548张val、1610张test-dev的图像/标签/元数据记录哈希。
- 核验实验66、67、68、69的22、9、8、17项选定存档哈希，共56项。
- 核验原始官方强对照及模型/校准器，按原阈值重算已有test-dev迁移判据。
- 重读跨尺度特征蒸馏原文，新增一篇架构组合负结果论文，核验PDF与Zotero附件。

主审计14.98秒，0图像解码、0检测器前向、0新AP评估、0优化器步。
另一次确定性重建也通过；它复用了同一个审计程序，不叫独立科学复审。
4项针对性测试覆盖正向记录保留、停止标签识别、漏追正向线索时报错、
未知历史结论格式不被默认为失败。

第一次审计把实验68的历史失败日志别名当作根目录文件名而中止。
原计划/源码和日志保留在engineering1目录。只补充别名到现有日志的
路径映射，仍要求原SHA256一致，没有改历史结果、指标或阈值。

## 不是“69次独立实验全部无效”

这些记录包含理想上界、信息诊断、工程核验、小头训练及官方复评，
存在共享模型、数据、缓存和递进关系。它们不是69个独立统计检验，
不能合并成小目标领域的失败率、显著性或不可能性结论。

| 证据链 | 保留的正向结果 | 当前不足与去向 |
|---|---|---|
| 1–7：质量、排序、保留与一致性 | 存在官方AP/AR正向点估计；实验5的小头种子有正收益 | 保留工程价值；同一已使用test-dev、仅小头种子变化，未建立独立确认与新机制 |
| 11→12、15→16：类别选择 | GT辅助的类别替换空间存在 | 后续可学习小头未通过固定门槛；不把理想空间当部署收益 |
| 18→19→20：稳定动作排序 | 三种子诊断收益；官方相对uniform平均AP仍为正 | 官方相对regret的平均AP为负；原STOP保留 |
| 21→22/23：原生候选缺失 | 有可补目标的GT辅助候选支持 | 检索、换坐标控制未通过；不把候选数量当AP |

| 60→61→62/66：原生好框 | 两半GT辅助好框差距重复存在 | 实际质量头和分类投影更新未超过强对照 |

也没有将某次STOP改写成“该机制的一切实现均无效”。

实验51、65还存在梯度数值复核限制，它们不能用作排除所有梯度优化方法的
干净反证。实验59只确认数值变换的工程性质，没有验证检测收益。

## 为什么不继续用这套搜索方式扩大投入

第一，当前局部修补没有给出可明确归因、重复确认且具有先例差异的候选。
正向理想上界说明问题存在，但后续匹配学习往往不能将它转成强对照之上的
收益。已有工程正值也不能因其为正而自动变成论文创新。

第二，近期64拟合/32筛选/17确认图都属于检测器训练集。它们能检验新小头
的留出效果，不能当作整个检测系统从未见过的数据。val和test-dev结果也已
多次用于判断。当前图像字节和名字在三分割之间没有交集，但这既不证明
地理/视频身份独立，也不证明已经发生过拟合；它说明继续事后选模块时，
不能再把这些结果称为新的盲确认。

第三，继续提高诊断编号并不能代替实际的表征学习实验。完整高分辨率教师、
新骨干、真实视频/事件数据等都没有被这一组冻结局部诊断复现或否定；
启动它们需要不同的数据与训练条件，也必须有已知正控制证明短小试验有
能力测到预期效应。不能用一个冻结旧表征的负结果“一次判死”它们。

第四，门槛问题需要如实保留。例如实验39只因一个GT失去固定误报保护，
不能说其AP没有效果；也不能看过结果后放宽保护再称原实验通过。
若未来重新立项，应在新结果前设置有实际含义的效应量、误报容忍和
不确定性政策。当前停止建议不是因为每个微小正值都不够大，
而是没有形成满足当前研究目标的完整证据。

## 原论文对未覆盖范围的约束

CSCWD（2609.30395v1）已经将YOLO高分辨率教师P2与学生P3对齐，
采用通道投影、空间插值和通道内空间KL，训练后移除教师和辅助映射。
本轮重读方法页4–5及消融页8。我们的实验52是同模型裁剪后的
GT中心类别分布诊断，不是该特征蒸馏的复现。它既不能否定CSCWD，
也不能把普通P2→P3蒸馏换名作为我们的新方法。

LAF-YOLOv10（2609.14560v1）报告一种多模块组合的负结果，讨论了
预训练权重转移不完整与模块交互。原文页10也明确说没有通过控制实验
单独证明权重转移假设。因此它只提示需要检查初始化和组合效应，
不能证明我们的YOLO11s、所有P2结构或小目标方法必然失败。

两篇均按版本保存PDF、核对首页与元数据，并回读Zotero父子附件及
存储/项目副本哈希。CSCWD复用旧附件，没有重复创建；LAF为新归档。
两篇均为预印本，未声称其结果经过我们复现。语义索引返回0处理，
所以不声称语义检索覆盖已验收。历史仍有三项未取得合法全文的记录，
这也限制了任何“先例已穷尽”的说法。

## 现在怎么做，以及什么条件下重新立项

现在保留现有工程基线、实验代码、存档和正负结果；不追加当前这些配方的
完整训练，也不继续用同一批已使用结果自动筛更多局部模块。

重新研究小目标仍然可以，但应形成新的明确项目条件：

1. 一个能在原始数据上观察到、且与现有STOP不同的具体失效。
2. 区分开发与确认的数据计划，说明骨干预训练及已有val/test-dev暴露。
3. 与最接近原论文的方法差异和普通匹配对照，不能只增加注意力、P2、
   蒸馏或损失名称。
4. 有已知正控制的实际学习小试，先验证短预算有辨别力，再用它判断新机制。
5. 在新结果前固定效应量、误报容忍与不确定性判据。

这不意味着必须先下载大型数据或盲目长训。本次没有启动这些工作，
也没有把它们当作已经证实有效的下一方向。

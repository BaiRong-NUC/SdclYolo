# 基于尺度与难度协同学习的无人机航拍小目标检测

- 研究场景：复杂背景下的无人机航拍图像目标检测。
- 项目目标：完成可复现的方法、实验和分析，用于期刊投稿；具体投稿层次由最终结果与目标期刊要求决定。

## 1. 研究范围与核心假设

采用单模态 RGB、水平框、有监督检测。主数据集为 VisDrone2019-DET；AI-TOD-v2 通过下载、版本和标注验收后，作为第二数据集。

第一版以 YOLO11s 为主基线，保留检测网络、输入流程与标签分配方式，主要修改训练损失。以 YOLO11n 检验方法在另一模型规模上的效果。YOLO26s 作为较新基线对照；移植方法到 YOLO26 不属于第一阶段，因为其端到端损失路径需要单独适配。

核心假设：

> 训练时，目标尺寸与模型当前的分类、定位表现可以共同指示监督需求。通过目标级联合权重，将部分监督权重从易检测目标转移到难检测小目标，可能改善小目标检测，同时避免无界放大个别样本。

需要回答四个问题：

1. 尺度与难度联合建模是否优于分别建模或简单相加？
2. 效果是否来自有针对性的权重分配，而非增加整体损失尺度？
3. 小目标收益是否以其他尺度、其他类别或背景误检恶化为代价？
4. 该效果能否在另一模型规模、另一数据集上复现？

第一阶段不加入 P2 检测层、注意力模块、图像切片或新标签分配策略。这些可用作比较方法，以便单独验证训练机制。

## 2. 候选创新点与证据要求

### 2.1 候选贡献一：目标级尺度与难度协同监督

**方案：** 将训练增强后目标的尺寸、分类偏差和定位质量结合，生成每个真值目标的监督权重。一个目标匹配的多个正样本共享对象级权重。

**拟解决的问题：** 固定尺度权重不能区别已经学好的小目标与仍难检测的小目标；仅按难度加权又可能把监督集中到较大目标或异常样本。

**需要证明：**

- 优于原始损失、仅尺度加权、仅难度加权。
- 优于尺度与难度简单相加，以及随机分配同分布权重。
- 目标级聚合相对于正样本位置级加权具有稳定收益或更好的训练稳定性。
- 收益主要出现在事先定义的小尺度／困难子集，而不是仅改变总体分数分布。

**边界：** 尺度加权、困难样本学习均已有大量研究。使用它们并不能自动构成创新；对象级聚合、联合机制及其效果必须与相近方法区分。

### 2.2 候选贡献二：有界且守恒的监督权重调节

**方案：** 对联合信号进行质量加权中心化，使原有正样本质量权重的总和保持不变；通过受限强度系数保证每个对象权重有上下界。训练早期采用渐进启用。

**拟解决的问题：** 无界加权可能放大极端样本；不控制总权重的方案可能只是改变有效学习强度，难以判断收益来源。

**需要证明：**

- 权重范围、守恒残差符合公式。
- 相比非守恒、无界、无渐进启用的对照，稳定性或检测效果有所改善。
- 相比对原始损失整体乘常数，仍有有效收益。

**边界：** 守恒的是正监督质量权重总和，**不是损失数值、梯度范数或训练计算量**。有界权重也不意味着能够自动识别或修正错标。

这是核心方法的稳定化设计。若没有独立证据，论文中将其并入贡献一，不为了数量硬拆成两个创新。

### 2.3 候选贡献三：局部困难背景约束，作为后续扩展

**方案：** 在目标外围、所有有效真值框与忽略区域之外，选择高置信度背景位置，施加小权重的附加负监督。

**拟解决的问题：** 提高小目标训练关注度后，局部纹理可能产生更多误检。

**启用条件：** 主方法确实出现召回改善但误检上升，且忽略区域处理已经正确。

**需要证明：**

- 优于随机背景采样、全图困难负样本选择。
- 在同等召回下减少误检，或在固定 FPPI 下提高召回。
- 不通过过度压低置信度牺牲小目标召回。

困难负样本挖掘属于已有技术，本项不是默认成立的独立创新。无稳定收益则删掉；论文主体仍为尺度与难度协同学习。

### 2.4 完成验证后可采用的贡献表述模板

以下是写作模板，不是已取得的结论：

1. 针对航拍小目标的尺度差异与学习难度差异，提出目标级尺度—难度协同监督机制，联合调节分类与定位学习。
2. 设计有界且保持正监督质量总量的权重调节方式，并采用渐进启用，提高训练可控性。
3. 在两个数据集与多种模型规模上开展对比、消融和错误分析，检验方法有效性及适用边界。

第三项是实验贡献，不应冒充新的算法模块。背景扩展是否替换第三项，由实验决定。

## 5. 方法定义

### 5.1 符号

| 符号 | 含义 |
|---|---|
| `i` | 当前 batch 中的一个有效真值目标 |
| `j` | 检测器的一个正样本位置 |
| `g(j)` | 正样本位置 `j` 匹配到的目标 |
| `P_i` | 目标 `i` 的正样本位置集合 |
| `q_j` | 原分配器给位置 `j` 的真值类别软质量值 |
| `p_j` | 位置 `j` 对真值类别的预测概率 |
| `I_j` | 预测框与匹配真值框的普通 IoU，范围 `[0,1]` |
| `S_i` | 尺度关注信号 |
| `D_i` | 难度信号 |
| `u_i` | 联合信号 |
| `w_i` | 应用于该目标正监督的权重 |

第一版只处理已经匹配到正样本且正质量和大于零的目标。没有正样本的目标保持原流程，并记录其占比。**该方法无法仅靠重新加权直接补救零正样本目标。**

### 5.2 尺度信号

使用经过当前训练几何增强后的框，宽高为 `b_w`、`b_h`，模型输入大小为 `H × W`：

```text
s_i = sqrt(b_w * b_h)
s_ref_i = s_i * 640 / sqrt(H * W)
S_i = 1 / (1 + (s_ref_i / s0)^2)
```

- `s_ref_i` 在 640 像素参考输入上描述目标尺度。
- `s0` 初始候选为 32，仅表示设计起点；需要验证集选择，候选 16、32、48。
- `S_i` 位于 `(0,1]`，较小目标具有更高尺度关注信号。
- 单阶段主实验固定输入 640，多分辨率实验分别训练，避免最初同时引入多尺度增强。
- Letterbox、Mosaic、裁剪后重新计算框尺度，不使用原图尺度代替当前监督尺度。

训练尺度与评价尺度是不同定义。论文中评价分桶按原始图像真值框计算，不能混用。

### 5.3 分类与定位难度

对正样本位置：

```text
d_cls_j = abs(p_j - q_j)
d_loc_j = 1 - I_j
```

以目标级平均聚合：

```text
D_cls_i = mean(d_cls_j, j in P_i)
D_loc_i = mean(d_loc_j, j in P_i)
D_i = alpha * D_cls_i + (1 - alpha) * D_loc_i
```

初始 `alpha = 0.5`；候选为 0、0.5、1，用于检验只用分类、只用定位以及联合估计。

注意：

- 分类难度衡量相对于软质量目标的偏差，不直接使用 `1 - p_j`，避免把质量软标签错误地当作 1。
- 对同一目标取平均，避免其难度简单随正样本数量增加；原分配器的质量总量仍可能与正样本数量相关。
- 难度、尺度与权重分支均使用 `detach`／`no_grad`，不通过权重公式反向传播。
- 普通 IoU 仅用于难度估计；回归项保持原基线的实际损失形式。
- 不稳定的 IoU 对极小框可能影响难度，必须通过消融检查。第一版不同时换成另一种距离损失。
- 持续高难度不等于错标，不把该信号宣传为标注噪声识别器。

### 5.4 联合信号与监督质量守恒

采用有界乘积作为首版联合机制：

```text
u_i = S_i * D_i
Q_i = sum(q_j, j in P_i)
Q = sum_i Q_i
mu = sum_i(Q_i * u_i) / Q
```

当 `Q > 0`：

```text
r(t) = clip((epoch - warmup_epochs) / ramp_epochs, 0, 1)
lambda_t = lambda_max * r(t)
w_i = 1 + lambda_t * (u_i - mu)
```

建议起点：`warmup_epochs=3`，`ramp_epochs=10`，`lambda_max=0.5`。

因为 `u_i`、`mu` 均在 `[0,1]`：

```text
1 - lambda_t <= w_i <= 1 + lambda_t
sum_i(Q_i * w_i) = Q
```

默认强度下，权重范围为 `[0.5, 1.5]`。这让高于当前质量加权平均值的联合信号获得更多权重，低于平均值的获得较少权重。

实现注意：

- `Q == 0` 时直接回退原损失，所有权重为 1。
- 守恒检查用原始 `Q`，不能用损失分母的 `max(Q,1)` 代替。
- 核心统计用 FP32，并容许浮点误差。
- 首版先使用单 GPU；DDP 版在各进程间归约 `Q` 与 `sum(Q_i*u_i)` 后计算全局 `mu`。
- DDP 的全局质量守恒不能直接推导出梯度范数守恒。
- 所有联合信号相同时，权重全部为 1，是预期行为。
- 乘积不是预先确认最优，必须与简单相加、仅尺度、仅难度比较。
- 第一版不引入按对象 ID 保存历史状态，避免 Mosaic 与裁剪产生身份跟踪问题。

### 5.5 分类损失的正确接入

对于分类 logit `z` 和软目标 `t`：

```text
BCEWithLogits(z, t)
  = t * softplus(-z) + (1 - t) * softplus(z)
```

首版只对正监督部分施加对象权重：

```text
L_cls =
  sum(
    w[g(j)] * t[j,c] * softplus(-z[j,c])
    + m_neg[j,c] * (1 - t[j,c]) * softplus(z[j,c])
  ) / max(sum(t), 1)
```

其中：

- `w[g(j)]` 仅对已匹配的真值类别正质量项生效，其他位置使用 1。
- `m_neg` 在有效匹配位置为 1；在忽略区域内的纯负样本位置为 0；其他位置为 1。
- 所有方法共用相同忽略掩码。
- 不直接将 `target_scores` 乘权重后送入 BCE；那会改变软标签和损失意义。
- 不把整个前景位置的所有类别 BCE 一起乘权重，以免连带放大其他类别的负项。
- 首版关闭额外类别权重；以后如启用，需重新定义并核查质量守恒的作用范围。

在 `lambda_max=0` 时，上式与具有相同忽略掩码的基线分类损失一致。默认 Ultralytics 不带本方案忽略适配的路径不属于这一等价性声明。

### 5.6 框回归与 DFL

保持原回归误差形式，在逐正样本项上施加同一对象权重：

```text
Z = max(sum_j q_j, 1)
L_box = sum_j(w[g(j)] * q_j * box_error_j) / Z
L_dfl = sum_j(w[g(j)] * q_j * dfl_error_j) / Z
L_main = gain_box * L_box + gain_cls * L_cls + gain_dfl * L_dfl
```

回归分母仍为原质量和，不重复归一化；分类软目标不变。

需要给回归损失扩展 `positive_weights` 参数，或暴露逐正样本项。不能通过已经求和的总回归损失乘一个标量代替对象级加权。

### 5.7 背景扩展，默认关闭

仅在主方法稳定并出现有证据的背景误检问题后实现：

1. 对每个有效目标框构造外围区域，外扩距离起点为 `max(8, 0.5*s_i)` 输入像素。
2. 从候选中排除所有真值框、其安全边界、所有忽略区域及所有正样本位置。
3. 在剩余位置按最大分类概率选 top-k；排名与类别选择均 detach。
4. `k = min(eligible_count, 64, max(1, ceil(0.5*N_pos)))`；无正样本或无候选时附加项为 0。
5. 仅对选中的最高预测类别加入负项，不把其他类别重复计入附加项。

```text
L_bg = mean(softplus(z_selected))
L_total = L_main + beta * L_bg
```

`beta` 默认 0；扩展候选 0.01、0.03、0.05。附加项与基础负监督存在重复，因此需记录两者比例，并比较随机采样和全图困难负样本。

这里的“背景位置”是训练掩码定义，不等同于已确认的检测误报；最终效果必须由检测级评价确认。

## 8. 对比与消融矩阵

### 8.1 核心消融

| ID | 配置 | 目的 |
|---|---|---|
| A0 | 原始损失 + 统一忽略适配 | 主基线 |
| A1 | 仅尺度信号 | 尺度贡献 |
| A2 | 仅难度信号 | 难度贡献 |
| A3 | 尺度与难度相加 | 与简单组合比较 |
| A4 | 尺度与难度乘积 + 有界守恒 | 主方法 |
| A5 | A4 改为位置级权重 | 对象级聚合贡献 |
| A6 | A4 去掉守恒，保留有界 | 守恒作用 |
| A7 | 对实际主方法权重做对象间随机置换 | 检验信号是否有针对性 |
| A8 | 原始损失整体乘常数 | 排除单纯训练强度变化 |
| A9 | A4 取消渐进启用 | 渐进启用作用 |

A1、A2、A3 也使用相同的有界守恒机制，分别设 `u=S`、`u=D`、`u=(S+D)/2`。A5 用各位置的难度替代对象均值，仍对质量加权信号中心化。A6 设 `w=1+lambda*u`，保留有界性但不中心化，并配套报告平均权重变化。A7 保持实际权重边际分布，需报告置换后质量守恒残差，并另设重新中心化版本以公平比较。

先用短程筛查接线错误和明显失败；不能凭短程排序删去关键对照后宣称完整方法最优。完整消融至少覆盖 A0–A6，诊断对照由核心结果决定补充。

### 8.2 外部比较

- 同配方训练的 YOLO11n、YOLO11s、YOLO26s。
- 增加分辨率的基线：例如 960，报告计算量与实测延迟。
- P2 检测头或固定切片基线：有稳定实现后加入，分别记录训练与推理成本。
- 标准困难样本重加权对照：明确其与 YOLO 软标签的兼容定义。
- 一至两项近期、公开实现、能够按相同数据协议复现的小目标方法。

## 9. 指标、复杂背景定义与评估

### 9.1 主指标

VisDrone 官方工具 [R4] 的 AP 使用 IoU 0.50–0.95、每图最多 500 个检测框；同时报告 AP50、AP75 和不同检测数量下的 AR。

本项目以官方协议为主：

- AP、AP50、AP75。
- AR500；需要时报告官方其他 AR 指标。
- 原图尺度分桶 AP／召回，作为补充。
- 固定 FPPI 下召回、误检数量及错误类型。
- 参数量、计算量、模型大小、训练吞吐与推理延迟。

预测导出时还原 letterbox 到原始坐标，固定置信度截断、NMS、`max_det=500` 与类别映射。导出结果按官方工具要求排序／截断。

不能将 Ultralytics 默认验证值直接称为官方 VisDrone AP。若实现 Python 评价，需与官方工具在小样本和已知匹配案例上核对，包括忽略区域、类别、重复检测与框数上限。

### 9.2 尺度分析

以原始图像真值框定义 `s = sqrt(width * height)`，补充分析使用：

- 微小：`s < 16`。
- 小：`16 <= s < 32`。
- 其余：`s >= 32`。

这些是本项目预先定义的分析分桶，不能冒称 VisDrone 官方尺度标准。使用面积筛选的 COCO 风格 AP 时，另写明完整评价定义。

评价不同尺度时，被排除的其他尺度目标需正确进入 ignore 处理，避免把它们的正确预测算成误检。

### 9.3 “复杂背景”必须可验证

第一版将“复杂背景”作为场景描述，不在方法公式中引入未经证明的背景复杂度分数。

附加分析预先制定以下子集：

- 目标密集程度：按有效目标数／图像面积计算，阈值由训练集分位数确定。
- 遮挡程度：依据保留的原始遮挡标注。
- 纹理干扰：训练集上确定纹理统计方式后冻结，在固定目标外围区域计算；忽略区域与有效目标区域排除。

纹理统计仅是背景复杂度的代理指标，不能等同于语义上的“复杂”。需抽样核查其排序是否合理，报告子集数量与类别分布，避免只挑有利图片。

错误分析区分背景误检、类别混淆、重复框、定位错误和漏检；先按明确匹配规则进行，不根据图片观感给模型判分。

### 9.4 速度评价

训练损失改动按设计不增加推理模块，但不提前报告“零延迟开销”。实际验证：

- 相同硬件、软件、精度、输入大小、batch=1。
- 预热后统计模型前向与包含预处理／后处理的端到端延迟。
- 对 GPU 计时进行同步，记录测量轮数与均值／分位数。
- 检查导出后的网络结构是否相同。
- 高分辨率、切片、P2 方法分别报告它们的实际成本。

## 10. 必要测试与验收

### 10.1 数据与评价

- 图像、框、类别映射和忽略区域转换正确。
- Letterbox、翻转、缩放、Mosaic 后，忽略区域与图像对齐。
- 原坐标导出与官方格式正确。
- 正确框、重复框、错误类别、忽略区域内预测等小案例与评价预期一致。
- 验证集与最终测试集职责分离。

### 10.2 损失与权重

- `lambda_max=0`、背景关闭时，前向损失与梯度和统一忽略基线一致。
- `w` 在理论范围内，权重分支不产生梯度。
- `sum(q*w)` 与 `sum(q)` 的相对残差满足预设浮点容差；FP32 起点为 `1e-5`，需按规模复核。
- 同一目标多个正样本权重一致。
- 空标签、空前景、极小框、边界框、单目标、全相同信号均不产生 NaN／Inf。
- 软标签 BCE 分解在 FP32 与原实现数值等价，AMP 下无异常。
- 回归与 DFL 权重只施加一次，损失分母与增益保持正确。
- 训练恢复后调度进度一致；DDP 归约无空 batch 死锁。
- 背景扩展不选中正样本、有效目标内部或忽略区域。

### 10.3 训练记录

每个 run 保存：

```text
source commit / patch hash
environment versions
dataset manifests and hashes
resolved config and seed
checkpoint selection rule
official evaluation outputs
weight / difficulty / unmatched-object statistics
timing and memory measurements
```

权重统计至少包含各尺度的 `S`、`D`、`w` 分布、总质量守恒残差、无正样本目标占比、分类与定位难度分布。

- 主方法长期不优于仅尺度／仅难度。
- 只靠调大训练强度获得收益。
- 小目标收益伴随严重的其他类别或尺度下降。
- 无正样本目标是主要漏检来源，而重新加权无法覆盖。
- 训练正常但方法与已有工作高度重合。

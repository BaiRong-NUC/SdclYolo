# 小目标课题收尾判断

结论日期：2026-10-13。

**建议放弃将“通用小目标检测改进”作为当前论文主方向，停止现有配方的后续训练。**

这是结合当前实验、创新边界与计算预算作出的投入判断，不是声称整个小目标领域
不可研究，也不是证明更大模型、不同数据或完整表示学习都无效。

## 当前结果为什么不足以支持继续投入

已按原始结果文件核验以下固定筛选，保留全部历史 STOP：

| 路线 | 通过门槛数 | 判定 |
|---|---:|---|
| 实例相位一致性 | 2/7 | STOP |
| 覆盖保护标签分配 | 1/5 | STOP |
| 视图条件救援打分 | 4/9 | STOP |
| 原框归属下定位增益选择 | 7/11 | STOP |
| 错排代价加权动作排序 | 6/10 | STOP |
| 冻结分类末层与小目标类别间隔 | 0/10 | STOP |

各行使用的对照、协议与门槛不同，不能把比例相加作为全领域的统计否定。
部分单项改善为正，但没有通过提前登记的匹配对照和机制要求。
GT 辅助的定位潜力诊断也不能等同于模型可学到或可部署的收益。

已有 548 张 val 被多次用于研究方案选择。继续在同一份 val 上堆模块、改损失、
挑种子或延长训练，不能解决独立证据不足的问题。
这轮分类预检只能否定其采样与冻结末层配方，不能据此宣称骨干特征没有信息；
其处理耗时也不是端到端部署 FPS。收尾判断依据的是整个投入记录。

文献中，ESOD 已讨论骨干特征复用与切片效率，SET 已讨论微小目标的特征与背景，
UGS 已讨论小目标定位梯度稳定性。这些是已核验的重合例子，不是穷尽所有论文。
仅再加通用切图、上下文、分类间隔或困难样本加权，不足以建立新的贡献。
具体来源和创新边界见同目录的 `960_testdev_transfer_and_research_decision.md`。

## 最后一次无训练、独立划分的迁移检查

使用本地 VisDrone2019-DET-test-dev 全部 1,610 张图片；原始图片及标注与原清单
一致。与 train/val 没有图像字节、图片名称或文件首段前缀重合。
文件名前缀检查不是地理独立性的证明。本次是本地官方协议评估，不是榜单提交。

只比较提前冻结的三个工程对照：单视图 960、五视图 Soft-NMS、普通校准版。
没有重新训练；没有改温度、门槛、类别或 checkpoint；预测阶段不读取测试标注。
原版 VisDrone 聚合逻辑与已验证的加速辅助函数保持不变。

| 版本 | 官方 AP | 官方 AR500 |
|---|---:|---:|
| 单视图 960 | 26.6268% | 37.6749% |
| 五视图 Soft-NMS | 30.3596% | 46.2505% |
| 普通校准版 | 30.8943% | 46.0182% |

固定迁移门槛：

| 指标 | 实际变化 | 门槛 | 是否通过 |
|---|---:|---:|---|
| 校准版 AP 相对 Soft-NMS | +0.5347 pp | >= +0.30 pp | 是 |
| 校准版 AP 相对单视图 | +4.2675 pp | >= +1.00 pp | 是 |
| 校准版 AR500 相对 Soft-NMS | -0.2324 pp | >= -0.10 pp | 否 |

因此为 **TRANSFER_STOP（2/3）**。
融合和普通校准的 AP 收益具有这一次跨划分证据，但校准的召回代价超过预设容忍范围。
保留这一取舍，不把它写成全面通过的强对照，不再在 test-dev 上调参。
工程收益与论文创新分开判断；收尾建议在官方 test-dev 结果出来之前已经写入方案。

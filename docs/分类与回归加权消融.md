# 分类与回归加权消融

日期：2026-10-06。

## 目的

现有 30 轮 SDCL 的小目标 AP50–95 从 18.929% 到 18.996%。固定置信度 0.25 下
Recall 增加约 0.843 个百分点，同时全图误检增加 793 个；近似相同误检数下，
小目标 Recall 增加约 0.151 个百分点，配对图像 bootstrap 区间包含零。
详见 [按尺寸评估与漏检分析](按尺寸评估与漏检分析.md)。

下一步分别测试分类与回归加权，判断哪些分支改善定位、排序或工作点表现。
分类加权改变置信度分布是待检验解释，尚未确认为误检增加的原因。

## 实现与对照条件

`sdcl.apply_to` 控制加权分支，`signal` 和 `difficulty_alpha` 仍控制权重信号。

| 配置 | apply_to | 正分类监督 | 框回归与 DFL |
|---|---|---|---|
| baseline.yaml | both，enabled=false | 原始损失 | 原始损失 |
| sdcl.yaml | both，省略时的默认值 | 加权 | 加权 |
| sdcl_cls.yaml | classification | 加权 | 原始损失 |
| sdcl_reg.yaml | regression | 原始损失 | 加权 |

仅改变权重作用分支。原始标签分配、软目标、背景分类处理、忽略协议与损失分母保持一致；
回归分支包含框损失与 DFL。两组均保留 `signal: joint`、`difficulty_alpha: 0.5`、
`lambda_max: 0.5`、3 轮权重预热与 10 轮渐进启用。
旧配置及旧检查点缺少 `apply_to` 时解释为 `both`；恢复训练仍拒绝改变分支。

两组新配置默认 YOLO11s、原始 `yolo11s.pt` 预训练权重、30 epoch、batch 8、
640 输入、seed 0、SGD、相同增强与 Windows workers 0。
本次检查逐项对比了历史 `sdcl_yolo11s_seed0/args.yaml`：
除 run 名称和输出位置外，训练参数一致。

## 2026-10-07：完整 BCE 分类加权

两组分支消融已经完成。分类首次 run 只训练到 23 轮，完整 30 轮模型位于
`output/runs/sdcl_cls_yolo11s_seed0-2/weights/best.pt`。分类结论使用修正后的报告
`output/analysis/size_30epoch_cls_corrected_20261007/report.json`，
旧的 `size_30epoch_cls_20261006` 不作为公平 30 轮对照。

| 方法 | small_all AP50–95 | 固定置信度小目标 Recall | 固定置信度全图 FP | 近似相同误检预算小目标 Recall |
|---|---|---|---|---|
| baseline | 18.929% | 47.124% | 10,139 | 47.124% |
| classification | 18.846% | 47.975% | 11,135 | 47.065% |
| regression | 18.943% | 47.241% | 10,231 | 47.140% |
| both | 18.996% | 47.967% | 10,932 | 47.274% |

固定置信度为 0.25。相同误检预算是基线工作点对应的 10,139 个全图 FP；
候选实际 FP 因置信度并列组略有不同。这些值来自统一的尺寸诊断协议，
不与原生 Ultralytics 或官方 VisDrone AP 混用。

下一步仅修改分类加权的数学形式，配置为 `sdcl_cls_full_bce.yaml`：

```yaml
sdcl:
  apply_to: classification
  classification_weighting: full_bce
```

旧方式 `positive_term` 对真实类别软标签 q 的正项加权：

```text
L = -w*q*log(p) - (1-q)*log(1-p)
```

新方式 `full_bce` 对这个真实类别项的完整 BCE 加权：

```text
L = w * [-q*log(p) - (1-q)*log(1-p)]
```

代码以 `target_scores > 0` 定位已匹配的真实类别项，其他类别及背景不加权。
目标权重仍由 `object_weights` 在无梯度模式下计算。固定 q 和正值 w 时，
新形式的单项最优概率仍为 q；这不保证整个检测模型的置信度校准或检测指标改善，
必须用下一组训练检验。回归与 DFL 在本配置中保持原始损失。

所有训练参数与完整的 30 轮分类消融一致。保持 joint 信号、
`difficulty_alpha: 0.5`、`lambda_max: 0.5` 和现有调度；从原始 `yolo11s.pt` 开始。
`experiment.json` 与检查点的 `sdcl_settings` 会保存 `classification_weighting`；
旧配置和历史清单缺少该字段时默认 `positive_term`。
恢复训练会拒绝更换分类加权形式。

训练指令：

```powershell

Set-Location 'D:\Python\YOLO'
python scripts/train.py --config configs/experiments/sdcl_cls_full_bce.yaml --epochs 30 --batch 8
```

首次输出为 `output/runs/sdcl_cls_full_bce_yolo11s_seed0`，
2026-10-07 准备时该目录不存在。同名重跑会递增 run 名，按实际保存位置评估。

训练成功完成后，先与原来的 30 轮基线做统一尺寸分析：

```powershell

  --baseline output/runs/baseline_yolo11s_seed0-2/weights/best.pt `

  --output output/analysis/size_30epoch_cls_full_bce_20261007
```

再将新报告与上述修正后的分类报告、回归报告和联合报告汇总比较。
主要指标仍是 small_all AP50–95 和多个相同误检预算下的 Recall；
同时查看全图 FP 与 tiny 表现。原有实验无需重新训练。

71 项测试通过，包含完整 BCE 非真实类别／背景的损失与梯度不变、固定软目标处

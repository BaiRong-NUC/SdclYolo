## 2. 版本安排

| 用途 | 版本 |
|---|---|
| PyTorch | 2.10.0，安装 CUDA 12.8 构建 |
| TorchVision | 0.25.0，与 PyTorch 2.10.0 配对 |
| Ultralytics | 8.4.172，与当前方案的版本声明保持一致 |
| NumPy | 2.2.6 |
| OpenCV | 4.12.0.88，要求 Python 3.12 下 NumPy >=2,<2.3 |
| 其余常用实验工具 | 在根目录 requirements.txt 固定直接依赖版本 |

官方 PyTorch CUDA 12.8 索引已确认存在上述两个包的 Windows CPython 3.12 wheel。租用 Linux GPU 服务器时，仍需核对目标驱动、平台和 wheel；不要仅依据服务器单独安装的 CUDA Toolkit 版本判断。

requirements.txt 包括图像处理、统计绘图、COCO 标注工具、TensorBoard、Jupyter 和 pytest。它固定直接依赖，不是完整的传递依赖锁定文件。

pycocotools 可以处理 COCO 风格标注与评价，但不能直接替代包含忽略区域等规则的 VisDrone 官方评价。

## 3. 安装命令

在 PowerShell 或 Anaconda Prompt 中依次执行：

```powershell
conda activate yolo
Set-Location 'D:\Python\YOLO'

python --version
python -m pip --version

python -m pip install --upgrade pip

python -m pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cu128

python -m pip install -r requirements.txt

python -m pip check
```

如果使用 Anaconda Prompt 的 cmd 语法，将 `Set-Location` 一行替换为：

```bat
cd /d D:\Python\YOLO
```

**先安装 GPU 版 PyTorch，再安装 requirements.txt。** 文件内的 `torch==2.10.0` 与 `torchvision==0.25.0` 接受匹配的 `+cu128` 构建，不会仅因为该后缀要求替换。若直接在空环境安装 requirements.txt，包索引可能选择不同构建，不能据此确认 GPU 可用。

`--index-url` 只用于上述 PyTorch 安装命令，不需要设置为全局 pip 索引。

## 4. 安装后验证

### 4.1 Python、依赖与 GPU

```powershell
python -c "import sys,torch,torchvision,ultralytics; print('Python:',sys.version.split()[0]); print('Torch:',torch.__version__); print('TorchVision:',torchvision.__version__); print('Ultralytics:',ultralytics.__version__); print('CUDA runtime:',torch.version.cuda); print('CUDA available:',torch.cuda.is_available()); print('GPU:',torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'unavailable')"
```

本机预期应看到 CUDA available 为 True，且 GPU 为 RTX 4070 Ti。具体运行结果需要安装后确认。

### 4.2 张量运算与 TorchVision CUDA 算子

```powershell
python -c "import torch; from torchvision.ops import nms; assert torch.cuda.is_available(), 'CUDA unavailable'; x=torch.randn(64,64,device='cuda'); y=x@x; boxes=torch.tensor([[0,0,10,10],[1,1,9,9],[20,20,30,30]],dtype=torch.float32,device='cuda'); scores=torch.tensor([0.9,0.8,0.7],device='cuda'); print('Matmul:',y.shape,y.device); print('NMS:',nms(boxes,scores,0.5).tolist())"
```

这一步比仅查询 CUDA availability 更能确认 Torch 与 TorchVision 算子配对。

### 4.3 常用分析工具

```powershell
python -c "import numpy,cv2,scipy,pandas,matplotlib,seaborn,sklearn; from pycocotools.coco import COCO; from torch.utils.tensorboard import SummaryWriter; print('Experiment imports OK')"
```

上述通过仍不等于模型训练验收。随后需用小样本检查模型加载、训练、保存、恢复与验证。

## 5. Jupyter 与 TensorBoard

注册当前环境的 Notebook 内核：

```powershell
python -m ipykernel install --user --name yolo --display-name "Python (yolo)"
```

启动 Jupyter：

```powershell
python -m jupyter lab
```

查看训练日志：

```powershell
python -m tensorboard.main --logdir runs
```

TensorBoard 需训练端实际产生对应事件日志，安装工具本身不会自动让所有 run 生成日志。

## 6. 固定完整环境

安装和验证通过后，再保存完整包列表：

```powershell
python -m pip freeze | Set-Content -LiteralPath 'requirements-lock-win-cu128.txt' -Encoding utf8
```

同时记录 GPU、驱动、Python、PyTorch 和项目源码提交。不同操作系统的完整锁文件应分别生成，Windows 锁文件不能自动视为 Linux 服务器的锁文件。

当前 Ultralytics 安装使用 PyPI 发布包，版本号与实现方案一致；相同版本声明不意味着一定等同于之前核查的某个 Git 提交。正式改源码前，另固定实际采用的提交或本地补丁。

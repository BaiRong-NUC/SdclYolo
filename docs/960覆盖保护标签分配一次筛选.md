## 本次研究问题

当前 Ultralytics 8.4.172 的 TAL 已把细小 GT 的候选区域扩到至少 16 像素。
因此单纯扩大候选框不能作为本项目的新贡献。
候选区域够大也不意味着 GT 最终有监督：多个 GT 竞争同一网格点，逐点按重叠消解后，
一个邻近目标可能保留多个点，另一个细小目标可能一个有效点都没有。

研究假设：在保留普通 TAL 的大部分分配时，只修复失去有效正样本的小目标，
并约束供方仍有监督，可以改善 tiny 的实际检测表现，且无需增加推理计算图。

训练集诊断先于候选训练，未使用验证图像调整补配规则：

- 在 64 张训练图的固定全图处理下：1874 个 tiny，75 个最终未覆盖，67 个在候选阶段有点。
- 在 64 张训练图的随机增强样本下：3814 个 tiny，331 个最终未覆盖，
  其中 260 个在冲突前有候选点，88 个存在满足框内/CIoU/供方冗余条件的潜在补配。
- 原始证据：`output/verification/coverage_20261012/assignment_audit.json`。
  这是一个训练集样本诊断，不能外推成全数据比例，不能把未分配直接等同于推理漏检。
- 实现后的独立训练图预检使用自己的固定随机序列：
  5673 个 small_all 中，未覆盖数 417 -> 249，补回 168 个；没有产生新的失去监督目标。
  这些计数是同一预测上的分配前后结果，不是 AP 收益。

## 冻结方法：CPR-TAL

暂用名 Coverage-Preserving Repair for TAL。名字仅用于识别实验，不代表已确认论文创新。

1. 完成原始 TAL 的候选筛选和重叠冲突消解。
2. 只处理参考尺寸 640 下 sqrt(area) < 32 且有效正样本数为零的 GT。
   有效正样本定义为已分配且 task-alignment metric > 0。
3. 补配点必须严格在真实 GT 框内，预测 CIoU >= 0.10，
   alignment >= 该 GT 所有可行框内候选最大 alignment 的 0.25。
   每个 GT 最多保留 13 个候选。
4. 候选越少的 GT 优先；同数量按 GT 索引处理，避免额外随机性。
5. 优先取未被有效占用的点；否则只能从拥有至少两个有效正样本的供方取一个点。
   对候选按 `recipient_relative_quality - donor_relative_quality / donor_positive_count` 排序。
6. 每个未覆盖 GT 最多补一个点；供方更新后始终保留至少一个有效正样本。
   实际修改 mask 后重新检查全体 GT 覆盖，不仅检查 Python 计数。
7. 保留原始 TAL 的质量软标签、归一化和原始 bbox/DFL 损失；不设置额外正标签下限。
8. 前 5 轮按原始 TAL，第 6 轮开始补配；不使用相位损失或 SDCL 重加权。

框内约束避免新增不可由非负 ltrb 表达的训练目标。本方法不会消除原始 TAL 的所有框外正样本，
也不能挽救根本没有可行框内点的目标。这些边界是有意限制的，避免把多个机制混入第一次实验。
贪心补配不保证全局最优或每个 GT 都能恢复；本轮不增加多跳匹配机制。

## 创新边界和相关工作

检索截至 2026-10-12：

- OTA (CVPR 2021) 已研究全局最优输运分配和拥挤场景匹配冲突，
  不能把“考虑 GT 竞争”或“全局分配”本身称为新思想。
  https://arxiv.org/abs/2103.14259
- RFLA (ECCV 2022) 已针对 tiny 的监督离群和样本不均衡提出高斯感受野分配及分层分配。
  https://arxiv.org/abs/2208.08738
- DSDL (Automation in Construction 2026) 已包含距离引导 TAL、Signed DFL 和 Densified DFL。
  因而带符号距离和近零加密 bins 不适合直接作为本项目原创点。
  https://github.com/yyksh97/DSDL
- DALA 已研究 tiny 的动态正负比例和密度影响，扩大正样本数/尺度加权也不够构成区分。
  https://github.com/cszzshi/DALA

本次候选贡献限定为：
**在原始 TAL 冲突后，对稀缺且可表达的小目标，做有质量约束的最小覆盖修复，
并显式保护供方覆盖。**
目前的检索没有证明这是首次提出，也没有足够依据承诺刊物等级。
只有筛选通过，才值得进一步比较 OTA/SimOTA、普通无保护补配、无框内约束补配等相关方法。

## 投资门槛

沿用现有五项检测收益门槛，全部通过才能 CONTINUE：

| 指标 | 要求 |
|---|---:|
| tiny AP50-95 变化 | >= +0.50 pp |
| small_all AP50-95 变化 | >= +0.30 pp |
| all AP50-95 变化 | >= -0.10 pp |
| small_all Recall at FPPI<=10 变化 | >= +0.50 pp |
| 该召回差值的图像配对 bootstrap 95% CI 下界 | > 0 |

任一项失败：STOP 当前补配方案，保留 960 基线，不追加权重或候选数量搜索来寻找正结果。
通过：仅表示值得投资，随后才做组件消融、多种子、独立数据集、官方 VisDrone 指标和相关方法对比。

评估前必须验证训练完成、配方/数据/源码/checkpoint 一致，且补配在预热后每轮真正启用，
供方失去覆盖计数为零。若这些条件失败，报告实验无效，不伪造 STOP 或 CONTINUE。
最后十轮的未覆盖比例改善仅作机制解释，不用它代替实际检测门槛。

双方推理尺寸固定 960，尺寸分组固定 reference_size=640，conf=0.001 收集 AP 曲线，
NMS IoU=0.7，max_det=500。FPPI 对比选择各自满足同一误检预算的阈值。
图像 bootstrap 不等于训练种子显著性。当前 COCO-style/IoF-ignore 诊断不是官方 VisDrone AP。

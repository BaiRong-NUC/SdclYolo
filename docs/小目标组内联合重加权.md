# 小目标组内联合重加权

日期：2026-10-09。状态：代码与配置已验证，真实训练由用户执行。

## 为什么做这一组

原版联合 SDCL 的三个种子平均整体诊断 mAP50–95 差值为 -0.026 个百分点，
tiny AP 平均 +0.146，small_all AP 平均 +0.098，中目标 AP 平均 -0.729 个百分点。
已有尺度／难度消融也已完成。seed 0 的记录如下：

| 方法 | 整体 Ultralytics mAP50–95 (%) | tiny AP50–95 (%) | small_all AP50–95 (%) | medium AP50–95 (%) |
|---|---:|---:|---:|---:|
| 基线 | 23.262 | 14.099 | 20.287 | 45.026 |
| 原版联合 | 23.360 | 14.316 | 20.478 | 44.659 |
| 仅尺度 | 23.305 | 14.258 | 20.307 | 45.167 |
| 仅难度 | 23.243 | 13.958 | 20.277 | 45.175 |

整体列来自报告的 `captures.*.ultralytics_metrics`，尺寸列来自
`coco_reference`。这两个指标体系分别比较，不交叉解释；均不是官方 VisDrone AP。
原始报告位于：

- `output/analysis/size_100epoch_seed0_20261008/report.json`
- `output/analysis/size_100epoch_scale_seed0_20261009/report.json`
- `output/analysis/size_100epoch_difficulty_seed0_20261009/report.json`

联合信号在 seed 0 的小目标 AP 上优于两个单独信号，但中目标 AP 较低。
因此保留联合信号，先改变参与权重归一化的目标范围。待检验假设是：
只在小目标内部重新分配监督质量，可能保留小目标收益并减轻其他尺寸的代价。
已有结果不能证明中目标下降由跨尺寸重加权导致，这一组也不能预先保证改善。

## 方法与实现

新增配置：

```yaml
sdcl:
  object_scope: small
  small_side_threshold: 32
```

旧配置缺省为 `object_scope: all`，沿用原公式。尺度、难度和联合信号
`signal: joint` 的构造保持一致，沿用匹配 GT 聚合、停止权重梯度和渐进启用。

对当前批次内已匹配且正质量大于零的目标 i：

```text
r_i = sqrt(augmented_box_area_i) * scale_reference / sqrt(image_H * image_W)
S = {i : r_i < small_side_threshold}
m_i = sum of assigned soft-target quality for object i
z_i = scale_i * difficulty_i
c_S = sum_{i in S}(m_i * z_i) / sum_{i in S}(m_i)
w_i = 1 + lambda(epoch) * (z_i - c_S), if i in S
w_i = 1, otherwise
```

同一个 GT 的所有有效正位置共用权重。分组与中心化跨当前批次进行，
不同图片的 GT 编号分别处理。代码用目标各正位置的平均参考边长判定分组。
阈值采用严格小于 32；恰好 32 的目标保持单位权重。
没有符合条件的匹配目标或只有一个时，权重均为 1。

组内 `sum(m_i * w_i) = sum(m_i)`，中大目标与背景保持单位权重，
因此总体正质量也守恒。默认强度不超过 0.5，权重位于 [0.5, 1.5]。
损失仍采用原版正分类项及回归／DFL 加权，标签分配、软标签和损失分母保持一致。

这里的尺寸来自增强后的 GT，并折算到参考尺度；不是原始标注尺寸，
也不代表训练分组和验证报告的尺寸分组逐目标一致。
中大目标直接权重为 1，不意味着其损失、梯度或 AP 保持不变：
网络参数共享，预测和后续匹配仍会随训练改变。质量守恒也不等于梯度守恒。

实现位置：

- `sdcl/config.py`：参数校验与旧配置默认值。
- `sdcl/weights.py`：小目标组内中心化和诊断统计。
- `configs/experiments/sdcl_small_group_100.yaml`：本次独立实验。

诊断增加 `eligible_objects`、`eligible_quality_mass`、
`eligible_mass_relative_error` 和 `ineligible_weight_max_deviation`。
后两项分别检查组内守恒误差和组外单位权重偏差；正常浮点误差需与实际数值一起看。

这是一项方法修订候选，是否有效需要真实实验，是否具备论文新颖性还需要相关工作对比。

SGD、相同增强和忽略协议，以及 3 轮预热、10 轮渐进、最大强度 0.5。
不从已有 SDCL 的 `best.pt` 或 `last.pt` 微调。

## 训练完成后执行评估

```powershell
python scripts/analyze_sizes.py `
  --baseline output/runs/baseline_yolo11s_100ep_seed0/weights/best.pt `
  --sdcl output/runs/sdcl_small_group_yolo11s_100ep_seed0/weights/best.pt `
  --imgsz 640 --batch 16 --confidence 0.25 --device 0 `
  --output output/analysis/size_100epoch_small_group_seed0_20261009
```

`--sdcl` 为候选模型参数。输出目录在预检查时未被占用；重复评估应使用新目录。
将新报告与上述三份历史报告比较，重点检查：

1. tiny／small_all AP 是否保留或改善原版联合的收益。
2. FPPI 5、10 下的小目标 Recall 是否改善，避免仅依赖固定阈值 Recall。
3. medium AP 是否减轻原版联合的下降，整体 AP 是否保持。
4. 固定置信度 0.25 的误检数是否继续增多，诊断权重是否满足预期。

组内重加权只有一个 seed 的结果时，只能用于方案筛选。
若小目标收益与其他尺寸的取舍改善，再固定方案补 seed 1、2；
若小目标收益消失，需考虑组内中心化限制了相对监督分配，而不是直接增加轮数。
已使用验证集筛选方法，正式论文还需独立测试与官方评价。

原版 seed 0 联合实验在 61 轮后中断并恢复，因此当前历史对照应披露这一点，
不声称恢复与连续训练逐位等价。
